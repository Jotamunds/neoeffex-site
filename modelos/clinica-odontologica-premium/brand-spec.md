# Auréa Odontologia — sistema visual

O sistema combina uma base marfim de leitura editorial com verde-petróleo preciso, grafite azulado e fotografia clínica discretamente dessaturada.

## Tokens

```css
--bg: oklch(97.3% 0.012 91);
--surface: oklch(99.2% 0.004 91);
--fg: oklch(21% 0.032 238);
--muted: oklch(47% 0.024 192);
--border: oklch(84% 0.022 100);
--accent: oklch(39% 0.065 184);
```

## Tipografia

- Display: `Iowan Old Style, Charter, Georgia, Times New Roman, serif`
- Interface e corpo: `Avenir Next, Avenir, Helvetica Neue, Segoe UI, sans-serif`
- Dados e microcopy: `SFMono-Regular, Consolas, Liberation Mono, monospace`

## Regras observadas

1. Títulos grandes usam uma serifada de contraste alto, com texto curto e quebra editorial.
2. O verde-petróleo surge como campo de impacto ou ação principal, nunca como decoração repetida.
3. A fotografia é ampla, com recortes conscientes e uma camada de baixa saturação para manter sofisticação.
4. Bordas servem à estrutura; painéis alternam blocos claros, blocos escuros e espaço em vez de uma sequência de cards iguais.
5. Microcopy mono cria precisão em índices, benefícios e números, sem competir com os títulos.
