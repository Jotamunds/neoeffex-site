# Auréa Odontologia

Modelo comercial visual para clínica odontológica premium da Neoeffex. A camada é estática e concentra a configuração em `assets/js/main.js` (`SITE_CONFIG`), sem backend, catálogo paralelo ou integração operacional.

## Estrutura

- `index.html` — landing page semântica e responsiva
- `assets/css/style.css` — sistema visual, layout e responsividade
- `assets/js/main.js` — menu móvel, agendamento demonstrativo e animações sutis
- `assets/img/` — fotografia localizada para o protótipo
