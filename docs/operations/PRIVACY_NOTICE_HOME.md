# Aviso de Privacidade — Formulário da Página Inicial (Neoeffex)

Este documento descreve de forma transparente o tratamento de dados pessoais coletados exclusivamente através do formulário de contato disponível na página inicial (`https://neoeffex.com.br/`).

---

## 1. Dados Coletados

O formulário de contato solicita apenas as seguintes informações:

| Campo | Obrigatoriedade | Finalidade |
| :--- | :--- | :--- |
| **Nome** (`name`) | Obrigatório | Identificação do contato para atendimento personalizado. |
| **E-mail** (`email`) | Obrigatório | Canal principal para envio de resposta comercial ou proposta. |
| **Empresa / Marca** (`business`) | Opcional | Contextualização do segmento de atuação do cliente. |
| **Objetivo do Projeto** (`brief`) | Opcional | Descrição prévia das necessidades e escopo desejado. |

---

## 2. Finalidade Exclusiva do Tratamento

Os dados fornecidos têm como finalidade **exclusiva**:
- Responder à solicitação de orçamento ou contato iniciada pelo próprio usuário;
- Permitir uma conversa preliminar para esclarecimento de dúvidas técnicas e comerciais sobre o projeto.

**Em nenhuma hipótese** esses dados são vendidos, compartilhados com anunciantes terceiros, transferidos para corretores de dados ou utilizados para envio de mensagens não solicitadas (spam).

---

## 3. Cookies e Rastreamento de Terceiros

Na versão atual da página inicial da Neoeffex:
- **Não há** cookies de rastreamento de terceiros, redes de anúncios ou pixels de remarketing ativos no código-fonte;
- O site não executa ferramentas que realizem cruzamento de dados com perfis externos de redes sociais sem o consentimento prévio do usuário.

---

## 4. Segurança e Envio

O envio das mensagens é realizado via requisição segura HTTPS para o endpoint de processamento (`FormSubmit`), que entrega a mensagem na caixa postal comercial da Neoeffex. O formulário implementa validações de entrada e timeout de segurança no navegador.

---

## 5. Direitos do Titular (LGPD — Lei nº 13.709/2018)

Em conformidade com a Lei Geral de Proteção de Dados (LGPD), o titular dos dados tem o direito de:
1. Confirmar a existência de tratamento de dados;
2. Solicitar a correção de dados incompletos, inexatos ou desatualizados;
3. Solicitar a eliminação dos seus dados pessoais coletados após o atendimento;
4. Revogar o consentimento para contatos futuros.
