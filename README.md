# Neo by Neoeffex — Landing Page

Landing page estática e responsiva para apresentar a IA Neo by Neoeffex.

## Estrutura

- `index.html` — landing page principal.
- `landing.css` — identidade visual, responsividade e animações.
- `landing.js` — apenas comportamento essencial: reveal no scroll, estado do header e ano automático.
- `style.css`, `servicos.html` e `contato.html` — arquivos anteriores preservados no projeto.
- `img/` — assets existentes da Neoeffex preservados.

## Princípios aplicados

- Sem frameworks ou dependências externas.
- Código pequeno e reutilizável por classes/componentes visuais.
- Efeitos decorativos usam `pointer-events: none` e `user-select: none`.
- Suporte a `prefers-reduced-motion`.
- Conteúdo e navegação continuam utilizáveis sem animações.
- Paleta principal: `#141414`, `#053E70`, `#0B87F4` e `#2795F5`.

## Publicação

Por ser um projeto estático, basta publicar a pasta no GitHub Pages, Vercel ou outro serviço de hospedagem estática.
