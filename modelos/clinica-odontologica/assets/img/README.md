# Imagens do modelo

As fotografias são ilustrativas; não representam uma clínica ou paciente real da AURA.

- `hero-clinica.webp`, `clinica-interior.webp`, `clinica-mobile.webp`: versões do consultório já referenciado no ZIP original, servidas pelo Unsplash em WebP.
  Origem: https://images.unsplash.com/photo-1629909613654-28e377c37b09
- `alinhador.webp`: fotografia do alinhador já referenciada no ZIP original, servida pelo Unsplash em WebP.
  Origem: https://images.unsplash.com/photo-1609840114035-3c981b782dfe
- A URL do hero original retornou HTTP 404; por isso, o consultório também foi utilizado na abertura.
- `favicon.svg`: monograma tipográfico A, criado para este modelo.

As versões locais eliminam a necessidade de carregar fotos de outro domínio durante a visita. Os caminhos editáveis ficam em `assets/js/config.js`. Em um projeto real, substitua por fotografias aprovadas pela clínica.
